## 支配項は「パース」ではなく「イベント配送」だった

改修前・6000 行・200 行/秒・119x21・アイドル差し引き 209.0M instr の配分:

| 層 | 割合 |
|---|---|
| Wakeup 送出 + 4ms 合流 + メインスレッド往復 | **35.8%** |
| VTE パース + Term 更新（alacritty） | 31.4% |
| ペインログの履歴取り込み（2 秒 tick） | 21.6% |
| PTY read | 9.2% |
| OSC tap | 3.6% |

配送コストは**行数ではなく PTY read の回数**に比例する。同じ 6000 行でも
「20 行ごとに 100ms 休む」= 353M に対し「1 行ごとに 5ms 休む」= **1565M（4.4 倍）**。
#814 の「書き込み回数依存ではない」は、まとめ書きしても**届く側の read 回数が
変わらない**ことによる見かけ。
