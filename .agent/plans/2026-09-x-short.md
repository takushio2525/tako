# X（Twitter）向けショート動画 #1284

> 約 3 分・**無音再生前提**のショート。#1081 の解説動画（10 分級）とは別の成果物で、
> 素材・スライド描画系・デザイン言語だけを共有する。
> タイムラインの正本は `scripts/promo/x-short-timeline.tsv`。
> 完成品は `~/Desktop/tako-promo/tako-x-short-v1.mp4`（リポジトリに入れない）。

## 方針

- **無音で伝わることが最優先**。X のタイムラインは既定でミュート再生されるので、
  意味は**大見出しの字幕**と映像だけで運ぶ
- **ナレーションを付けない**（`TAKO_PROMO_NO_NARR=1`）。理由: 音を足しても無音再生では
  読まれず、逆にナレーション尺が区間長を駆動すると「読み切れない字幕」が生まれる。
  尺は `min_dur` で明示的に決め、字幕は 1 行が読める長さ（7〜13 秒）に置く
- **小さなサブタイトル行は使わない**（#1081 と同じ・ユーザー指示）。`subtitle` 列は常に `-`
- 字幕は **68px**（`TAKO_PROMO_CAPTION_PX=68`）。既定の 52px はスマホで小さい
- BGM は `make-bgm.py` が波形から合成した自作音源。**外部素材ではないので権利上の問題がない**
- 撮り直しはしていない。v1〜v4 の収録素材と #1081 v6 のスライドだけで組んである

## 2:20 問題

X の通常アカウントの上限は 2 分 20 秒（3 分は Premium 前提）。そこで
**2:11（131 秒）で 1 本として完結する**ように並べ、その後を「おまけ」にした。

- `x_cta1`（brew 1 行のスライド）が 121〜131 秒。**2:20 版の切り出し点は 131 秒**
- 131 秒までで「散らかる → 1 グループ = 1 タブ → master が担当を立てる →
  かんたん表示 → 入手方法」が閉じる
- 131 秒以降は 永続化 → スマホ → Windows → CTA 再掲

## 縦版について

**作っていない。** 1920x1080 の横版が正で、X のタイムラインでは横位置のまま再生される。
縦版（1080x1350 / 1080x1920）は実 UI のスクリーンショットを大きく切り落とすことになり、
「同じタブに担当 AI が並ぶ」という**画面の広がりそのものが売り**の絵が成立しない。
必要になったら、実 UI 区間だけ拡大トリミングし、スライドは縦用に別レイアウトで
描き直す（`deck.css` のスライド寸法を変えれば `render-slides.mjs` はそのまま使える）。
