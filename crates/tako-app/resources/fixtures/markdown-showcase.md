## テーブル（GFM）

列の配置指定（`:---` / `:---:` / `---:`）が反映されること。

| コマンド | 既定値 | 説明 |
|:---------|:------:|-----:|
| `tako theme` | dark | UI テーマの切替。引数なしで現在値 |
| `tako lang` | auto | 表示言語（日本語 / 英語） |
| `tako autosuggest` | on | 入力予測のゴースト表示 |

セルが空・セル内に装飾がある表:

| 項目 | 状態 | 補足 |
|------|------|------|
| **必須** | 完了 | `--yes` で対話なし |
| 任意 |  | 空セル |
| ~~廃止~~ | — | [詳細](https://example.com/docs) |

長いセルを含む表（折り返しの確認）:

| キー | 値 |
|:-----|:---|
| 長い説明 | この列にはとても長い文章が入る。折り返しが起きても行が重ならず、隣の列を押し出さないことを確認する。 |
| 短い | ok |

## コードブロック

言語指定つき（シンタックスハイライトが効く）:

```rust
/// ペインを分割して新しいシェルを開く
pub fn split(&mut self, direction: Direction) -> PaneId {
    let id = self.next_id();
    self.tree.split(self.focused, direction, id);
    id // 新しいペインの ID を返す
}
```

```sh
tako split --right && tako send --pane 2 'cargo test --workspace'
```

言語指定なし（等幅の素表示になる）:

```
tako list
  pane 1  role=master  cwd=~/dev/tako
  pane 2  role=worker  cwd=~/dev/tako
```

コードブロックの中に ``` を含む例（4 連バッククォートで囲む）:

````md
```rust
fn main() {}
```
````

## 引用

> 引用の 1 段目。設計の意図をここに引く。
>
> > 引用の 2 段目（ネスト）。さらに内側の補足。
>
> - 引用の中のリスト
> - 引用の中の `コード`

## リスト

深いネスト（4 段）:

- 第 1 段
  - 第 2 段
    - 第 3 段
      - 第 4 段
- 第 1 段（2 つ目）

番号付きリスト:

1. 最初の手順
2. 次の手順
   1. 入れ子の番号付き
   2. その次
3. 最後の手順

リスト項目が複数ブロックを持つ場合（マーカーは 1 回だけ）:

- 一段落目の説明。

  二段落目。ここにマーカーは出ない。

  ```sh
  echo "項目の中のコードブロック"
  ```

タスクリスト:

- [x] 完了した項目
- [ ] 未完了の項目
- [ ] 未完了 + `コード` + **強調**
