- 進行中の操作: {{operation}}
- 取り込み先（ours / 現在のブランチ）: {{ours}}
- 取り込み元（theirs）: {{theirs}}
- 未解決ファイル（{{file_count}} 件）:
{{files}}

## やること

1. まず `git status` と `git diff` で状況を自分の目で確認する
2. 未解決ファイルを 1 つずつ開き、`<<<<<<<` `=======` `>>>>>>>` のマーカーを読んで
   **両側の意図を理解してから**解消する。片側で機械的に上書きしない
3. どちらを採るか判断できない箇所があれば、そこで手を止めて人間に質問する
4. 解消したファイルは `git add <path>` でステージする
5. 全部終わったら、**何をどう解消したか**をファイルごとに 1〜2 行で報告する

## 禁止事項

- **勝手に commit / push しない**（`git commit`・`git push` は実行しない）。
  ステージまでで止めて報告し、コミットは人間の判断に委ねる
- `git merge --abort` / `git reset --hard` / `git checkout --ours|--theirs` の一括適用など、
  **人間に相談せずに状態を巻き戻したり片側を捨てたりしない**
- コンフリクトと無関係なファイルの変更・リファクタリングをしない
- マーカー（`<<<<<<<` 等）を消し忘れたまま「解消した」と報告しない
  （最後に `git grep -n '<<<<<<<'` で残骸ゼロを確認する）
