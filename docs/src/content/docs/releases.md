## v0.8 系（2026-08-28 〜）— 最新の安定版は v0.8.0

**安定版は v0.8.0**（2026-08-28）です。そのあとに出ている v0.8.1 〜 v0.8.17（2026-09-22 時点）は毎晩自動で出るテスト版で、この節は v0.8 系のタグ 18 本ぶんをまとめた読み物です。

柱は 4 つ。**スマホから tako を丸ごと使える**ようになったこと、**「人がやること」が 1 か所に集まる**ようになったこと、**セットアップが案内から代行へ**変わったこと、そして **claude 以外のエージェントも claude と同じように動く**ようになったことです。

### 安定版とテスト版（夜間リリース）

tako のリリースには 2 種類あります。

| 種類 | 出かた | GitHub Releases での表示 |
|---|---|---|
| **安定版** | 区切りがついたときに手動で昇格させる | Latest |
| **テスト版** | main に変更があった夜だけ自動で出る | Pre-release |

ステータスバーの更新通知は**この 2 つを別々に見ています**。両方あるときは「更新あり（安定版 + テスト版）」と出て、どちらを入れるか選べます。テスト版を選んだときだけ「不安定な可能性があります」の確認が 1 回入ります。急がないなら安定版のままで構いません。

### スマホから tako を丸ごと使えるようになりました

v0.6.0 で Tailscale へ一本化したリモートアクセスを、**スマホだけで仕事が回る**ところまで広げました。

- **会話を Claude 公式アプリへ預けられます** — プロファイルで許可すると、その master / solo の会話が Claude の Remote Control へ 1 対 1 で公開され、外出先から公式アプリでそのまま続けられます
- **スマホから新しく立てられます** — リモート画面の「+」から、AI チーム（master）・ターミナル・SSH ターミナルの 3 種類をその場で起動できます
- **ファイルを見て、直して、保存できます** — リモート画面にファイルビューが付きました。Finder のようにこのマシン全体をたどれて、よく使う場所はショートカットに登録できます。SSH 先のファイルも同じ画面から扱えます
- **接続先を切り替えられます** — SSH の接続先の切り替えと新規接続がスマホから行えます
- **端末ごとに権限を決められます** — 登録した端末に「閲覧だけ」「操作できる」「管理もできる」を割り当てられます。権限が足りないときは理由と導線が画面に出ます。権限を上げるのは Mac の画面だけで、下げる・消すは `tako remote devices` からもできます

土台も作り直しました。中継先をループバック TCP へ寄せて**全リクエストが 502 になる**問題を根治し、serve 設定の定期自己検査と自動復旧を入れ、「起動中を名乗ったまま tailnet から見えない」状態を無くしました。**一度起動していれば、tako や Mac を再起動しても自動で戻ります**。

詳しくは[リモートアクセス](/features/remote/)へ。

### 「人がやること」が 1 か所に集まるようになりました

AI に任せていると、レビュー・承認・投稿のような**人にしかできない用事**が会話の中を 1 行で流れていって見失います。v0.8 では、これを専用の入れ物に集めるようにしました。

- AI が起票した用事が**右パネルの tasks ビュー**に並びます。タブのラベルの右に未完了の件数が出ます
- その場で返答すると、**起票した master の入力欄へそのまま届きます**。master が閉じていれば、同じプロファイルの master を新しいタブに起こして渡します
- **スマホからも片付けられます**。添付されたファイルは、行を押すだけでその場で開けます

詳しくは[人がやること（ユーザータスク）](/features/user-tasks/)へ。

### セットアップが「案内」から「代行」へ

`tako setup` は、足りないものを**見つけて教える**だけでなく、**その場で入れる**ようになりました。

- Windows では Claude Code を自動でインストールします。失敗したときはエージェントに引き継いで解決を試みます
- macOS では任意の依存ツールをその場で導入できます
- 対象が claude だけでなく **codex / agy** に広がりました。何も入っていない状態から、3 つとも同じ手順で始められます
- 使うモデルは、エージェントごとに**実際の一覧を取得して**選べます

### claude 以外のエージェントも同じように使えます

codex / agy を claude と同じ土俵に乗せました。

- **利用上限で止まっても自動で復帰します** — codex は構造化されたデータから残量を読みます。あわせて、クレジット切れや組織の上限のような**時間では解けない利用阻害**を、待てば直る上限とは別物として検知するようにしました
- **完了検知が claude と同等になりました** — agy は実況ログを一次シグナルとして使います
- **worker からも tako の MCP を呼べます** — codex / agy の worker が tako の画面操作を使えます
- **再起動しても会話ごと戻ります** — claude に加えて codex / agy も、tako を立ち上げ直すと前の会話の続きから再開します

どのエージェントで何がどこまでできるかは[エージェント対応状況](/agent-support/)にマトリクスがあります。

### 会話を失わないための作り込み

- エージェントペインの右クリックから「**会話を引き継いだ再起動**」ができます（ハーネスごと入れ替える / 引き継ぎ文を書いて渡す の 2 種類）
- 再起動後の claude の再開が「起動途中の未検出」で自壊していた問題を根治しました
- 終了シグナルを受けたときもレイアウトを保存してから終わるので、タブが消えにくくなりました
- ネットワークが切れても SSH のペイン・タブ・リモートフォルダを失わず、回線が戻ったら自動で再接続します

### ワークスペースまわり

- **ファイルツリーに git のステータス**が色とバッジで出ます
- **Finder からターミナルペインへドラッグ&ドロップ**するとパスが入ります（複数選択は空白区切り）
- ターミナル上のパスは <kbd>Cmd</kbd>+右クリックでメニューが出ます。`~` で始まるパスも <kbd>Cmd</kbd>+クリックで開けるようになりました
- ファイルツリーの取りこぼしを 3 つ直しました。1 ディレクトリ 500 件を超えたぶんを黙って捨てる / 消えたフォルダを読み続ける / フォルダへのシンボリックリンクがファイル扱いになる、の 3 つです
- **スクロールバックの保持行数**を設定できるようになりました
- 起動フォルダ（cwd）をプロファイルごとに設定できます
- タブを「ー」の向きに送ると**タブごとたまり場へ退避**でき、たまり場のカードを押せば戻ります

### 軽さと堅さ

- 裏のタブの寸法合わせと、2 秒ごとに全ペインを丸ごと走査していた処理を見直し、**常時流れる仕事を減らしました**
- リモートの HTTP 受信を並列化しました
- アプリ内アップデートで **Dock のピン留めが外れる**問題を根治しました
- 濁点・半濁点が分かれた文字（NFD）が画面テキストから落ちる問題を、3 つの経路まとめて直しました
- データディレクトリが深い場所にあると内部通信が黙って縮退する問題を直しました
- セキュリティでは、ループバック経由の偽装ヘッダを接続元プロセスの検証で塞ぎ、PDF のリンクと提案チップにスキーム検査を通し、実行を拒否する判定を締めました

### Windows

配布物は v0.7.9 から macOS と同じリリースに載っています。v0.8 では**実機での動作**を詰めました。

- 実機の GUI セルフテストが完走するようになりました（メインスレッドのスタック予約量を宣言してクラッシュを根治）
- SSH ペインが無言で死ぬ問題、GUI 表示モードのスターターへ到達できない問題を直しました
- キーボードショートカットの表記が、Windows で実際に押すキーで出るようになりました
- URL を開く経路から `cmd.exe` を外しました

現在の対応状況は [Windows 対応状況](/windows-support/)にあります。

### そのほか

- **ドキュメントサイトを `tako.takushio2525.com` へ移しました**
- Web ビューを見たあとターミナルへ戻るとキー入力が届かなくなる問題を直しました
- Markdown プレビューが UTF-8 BOM を剥がさず、先頭行の見出しを潰す問題を直しました
- 蓋を閉じても作業を続ける設定を、バッテリー駆動のときにも（明示的に許可すれば）使えるようにしました
- 検索のヒット位置が、小文字にするとバイト長が変わる文字でずれる問題を直しました
- 夜間のテスト版リリースで、次に出す版数（minor / major）を予約できるようになりました

## v0.7.0（2026-08-15）

v0.6.0 以降にテスト版チャンネルで検証してきた変更をまとめた安定版です。柱は 3 つ。**ターミナルを知らなくても使える表示モード**、**動作の軽さ**、そして **AI との連携の底上げ**。

### ターミナルを知らなくても使える「GUI 表示モード」

タブバーのボタン（またはコマンドパレット）で表示モードを **GUI** に切り替えると、tako の見え方が変わります。

- **何も動いていないペインが 3 つのボタンになる** — 「AI チームに任せる」「AI と 1 対 1 で話す」「コマンド入力へ」。コマンドを覚えていなくても始められます。プロファイルが複数あるときは右端の **▾** から選んで起動できます
- **AI と対話中のペインが会話画面になる** — 発言が吹き出しで並び、Markdown も表として描画されます。ツールの実行や思考は折りたたまれ、必要なときだけ開けます
- **会話をドラッグして選択・コピーできる** — 発言をまたいだ選択も、発言ごと・コードブロックごとのコピーボタンもあります
- **承認ボタン・入力欄・スラッシュコマンドのボタン**（/compact・/clear・/help）が画面上に出ます
- コンテキストの残量がバーで見え、残りが少なくなると「/compact で会話を軽くする」ボタンが出ます

切り替えは**見た目だけ**です。動いているプロセスやセッションには一切影響しないので、いつでも往復できます。

### 目に見えて軽くなりました

画面の描き方を根本から作り直し、**同じ画面を出すのに使う CPU をおよそ 1/4〜1/3 まで**減らしました。

- 裏のタブが大量に出力していても、見えていないものは描き直さなくなりました（実測で CPU 22.3% → 2.6%）
- タブをたくさん開いているときほど効きます（17 タブ表示中で 36.65% → 8.94%）
- ついでに長く残っていた描画のバグも直りました。**下線が表示されない**問題と、**全角文字が続く行で文字が少しずつ左にずれる**問題です

### AI との連携

- **AI が提示したコマンドをワンクリックで実行** — AI が会話の中に書いたコマンドは、折り返しのせいでコピーすると壊れることがありました。専用のカードで提示されるようになり、コピーとその場での実行ができます
- **AI が長く働けるようになりました** — 会話が長くなって限界が近づくと、AI が自分で後任に引き継ぎます。引き継ぎ後も同じタブで作業が続きます
- **指示の取りこぼしがなくなりました** — AI が作業中でも指示が確実に届くようになりました（長文もそのまま届きます）
- **設定を機械間で共有できます** — `tako config` で、AI への指示ファイルや tako の設定を git リポジトリ 1 本で別のマシンと同期できます。パスワードやトークンは仕組みとして共有されません

### そのほか

- **Markdown プレビューの品質が上がりました** — 表がちゃんと表として描かれ、見出しやコードの配色も作り直しました。リンクは <kbd>Cmd</kbd>+クリックでブラウザへ、コードブロックにはコピーボタンが付きます
- **ライトテーマでコードの色が読めない**問題を修正しました
- **設定画面にプロファイルのタブ**が増え、AI の起動設定をフォームで編集できます
- **アップデートの案内**を専用画面と上部の通知カードに作り直しました。リリースノートも読みやすく表示されます
- Finder の「このアプリケーションで開く」に tako が出るようになりました
- 日本語入力の変換位置がずれる問題、git パネルのボタンが反応しない問題など、多数の不具合を修正しています

## v0.6.0（2026-07-27）

安定版ローンチ。v0.5.x のテスト版チャンネルで検証してきたリモート接続の全面刷新を安定版として正式に提供し、オーケストレーションの検知系を根本から直した上で、初回起動の導線・入力予測・ファイルツリー・git タブの使い勝手を整えました。

### リモート接続を Tailscale へ一本化

スマホからの接続を [Tailscale](https://tailscale.com/) Serve だけに刷新しました。以前の Cloudflare 経由の公開 URL・URL 埋め込みトークン・平文 LAN モードはすべて廃止されています。

- 接続先は **tailnet 内限定の恒久固定 URL**（毎回変わらない）
- 通信は WireGuard で**エンドツーエンド暗号化**。経路上の第三者に読まれません
- 認証は **Tailscale identity + 機器ペアリング**の二層。tailnet 内の端末でも、Mac の画面で承認するまで画面を一切見られません
- 設定は `tako remote setup` の対話ウィザードで完結します

詳しくは[リモートアクセス](/features/remote/)、以前のバージョンからの移行は[移行ガイド](/guides/remote-migration/)へ。

### オーケストレーションの検知を根治

長く残っていた 4 つの不具合を、実測で原因まで降りて直しました。いずれも「画面の文言を当てにいく」のをやめ、構造（文字が薄いかどうか、ダイアログが入力欄を奪っているか、画面が変化しているか）で判定するようにしています。

- worker が終わったのに完了イベントが出ない
- 生成中に人間が打った指示が消える
- 権限確認の待ちが「質問」として報告される
- worker 起動時の最初の指示が届かない

### 入力予測を既定で ON に

コマンドを打ち始めると、履歴から続きが薄い文字で予測表示されます。<kbd>→</kbd> または <kbd>Tab</kbd> で確定。**tako が開いたシェルの中だけ**で効き、`~/.zshrc` は書き換えないので、tako の外のターミナルは何も変わりません。切り替えは設定画面 / `tako autosuggest` / AI への依頼のどれでもできます。

### 初回起動の導線

初回だけタブバーの下に案内バナーが出て、`tako setup` → `tako master` をその場のボタンから実行できます（<kbd>Cmd</kbd>+<kbd>K</kbd> のパレットにも常設）。あわせて、tako 内のシェルには同梱 CLI のパスが自動で通るので、ZIP でインストールした場合でも `tako` コマンドがすぐ使えます。

### そのほか

- **git タブでブランチ操作とコンフリクト解消** — 切替 / 作成 / マージを追加。破壊的な操作は既定では実行せず「何が起きるか」を先に出します。コンフリクトは AI エージェントを立てて解かせることもできます
- **AI 自動リネームの品質改善** — 短時間での付け直しを抑制し、一時的なエラーを名前の材料から除外。出力言語を UI の表示言語に固定しました
- **更新チェックのプラットフォーム対応** — 「自分の OS 向けのアセットがある最新リリース」を探すようになり、「更新はあるが入れられない」通知が出なくなりました
- Windows は移植の基盤（抽象境界・対応マトリクス・クロスコンパイル CI）までが入りました。この時点では**配布物は macOS のみ**でした（**v0.7.9 以降は Windows の配布物も同じリリースに載ります** → [セットアップ](/getting-started/#方法-c-windowsインストーラー--ポータブル-zip) / [Windows 対応状況](/windows-support/)）

- **アプリ内アップデート** — インストール方法を自動判別し、確認 → 更新 → 自動再起動まで
- **オーケストレータープロファイル** — モデルや設定の異なる master を使い分け
- **スマホ用リモート画面の刷新**、mp4 動画プレビュー、公式ドキュメントサイトの公開
- tmux が無い環境での改行入力・タブ復元の不具合を修正

## v0.1.0（2026-06-26）— 初回リリース

- **ターミナル基盤** — タブ・ペイン分割・256 色 / truecolor・選択コピー・日本語入力（IME）のインライン変換
- **CLI と内蔵 MCP サーバー** — `tako` コマンドによる画面操作と、AI エージェントからのゼロ設定連携
- **パッシブ検知** — dev サーバーのポート検知チップ、タブ・ペインの AI 自動リネーム
- **ワークスペース機能** — ファイルツリー、シンタックスハイライト、Markdown プレビュー、git graph
- **tmux バックエンド永続化** — 再起動しても実行中プロセスと画面内容を完全復元
- **オーケストレーター** — `tako master` によるマルチエージェント連携
