入れたあとの 10 分で、**AI に画面を任せる**ところまで進みます。スクロールすると、画面がその手順の状態に変わります。macOS でも Windows でも同じ流れです（違うところは各場面の終わりに書いています）。

まだ入れていなければ、先に[インストール](/getting-started/)を済ませてください。

## 次は、AI チームに任せる

ここまでできたら、司令塔の AI（master）を起動してみてください。やってほしいことを日本語で 1 回伝えると、master が担当の AI（worker）を同じタブに並べ、確かめてから報告します。

<Cmd>tako master</Cmd>

流れは[オーケストレーションとは](/features/orchestration/)、話しかけ方の実例は[tako master 実践ガイド](/features/orchestrator/)で見られます。
