<section class="tako-section">
<h2 class="tako-section-title"><span class="tako-section-dash">—</span> ほかにも</h2>
<p class="tako-section-lead">ターミナルそのものが AI の作業台になります。人がキーボードでできることは、AI も同じ経路でできます。</p>

<div class="tako-card-grid">

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-pink"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M13 2 3 14h9l-1 8 10-12h-9l1-8Z"/></svg></div>
<h3>内蔵 MCP サーバー</h3>
<p>tako の中で AI エージェントを起動すれば、設定ゼロでペインの分割・コマンド実行・ファイル表示ができます。「隣のペインで dev サーバー起動して」と言うだけ。<strong>162 個</strong>の MCP ツールを内蔵しています。<a href="/features/mcp-server/">詳しく →</a></p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-green"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><rect x="3" y="3" width="18" height="18" rx="2.5"/><path d="M3 9h18M11 9v12"/></svg></div>
<h3>タブ＆ペイン管理</h3>
<p>エージェント・dev サーバー・ログを 1 タブにまとめられるので、どのプロジェクトで何が動いているか一目でわかります。AI が分割したペインは、頼んだ AI と同じタブに並びます。<a href="/features/tabs-and-panes/">詳しく →</a></p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-green"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M21 12a9 9 0 1 1-3-6.7"/><path d="M21 4v5h-5"/></svg></div>
<h3>閉じても消えない</h3>
<p>tmux（Windows では psmux）があれば、tako を閉じて開き直しても実行中のプロセスと画面がそのまま戻ります。PC を再起動したあとも、AI との会話を続きから再開できます。<a href="/features/tmux-backend/">詳しく →</a></p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-pink"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M14.5 2H7a2 2 0 0 0-2 2v16a2 2 0 0 0 2 2h10a2 2 0 0 0 2-2V6.5Z"/><path d="M14 2v5h5"/><path d="M9 13h6M9 17h4"/></svg></div>
<h3>プレビューとエディタ</h3>
<p>ファイルツリーから開いたコード・Markdown・画像・PDF をペインで表示し、その場で編集できます。macOS 版は言語サーバ（LSP）の診断・補完・定義ジャンプにも対応します。<a href="/features/file-preview/">詳しく →</a></p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-pink"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M6 3v12"/><circle cx="18" cy="6" r="3"/><circle cx="6" cy="18" r="3"/><path d="M18 9a9 9 0 0 1-9 9"/></svg></div>
<h3>git パネル</h3>
<p>ステージング・コミット・ブランチ切替・マージまで右パネルで。コンフリクトは AI に解かせることもできます。<a href="/features/git-integration/">詳しく →</a></p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-green"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="5" r="2.4"/><circle cx="5" cy="19" r="2.4"/><circle cx="19" cy="19" r="2.4"/><path d="M12 7.4v3.6M12 11h-7v5.6M12 11h7v5.6"/></svg></div>
<h3>エージェントを選べる</h3>
<p>Claude Code・OpenAI Codex CLI・Antigravity CLI のうち、入っているものを <code>tako setup</code> が見つけてそのままつなぎます。ローカル LLM でも動かせます。<a href="/agents/">詳しく →</a></p>
</div>

<p class="tako-section-lead">入れ方は OS ごとに 1 つずつ。そのあとは 2 コマンドで AI と作業を始められます。</p>

<div class="tako-os-grid">

<div class="tako-os-card">
<p class="tako-os-name">macOS</p>
<p class="tako-os-req">Apple Silicon の Mac</p>
<Cmd>brew install --cask takushio2525/tako/tako</Cmd>
<p class="tako-os-note">Homebrew を使わないなら、GitHub Releases の zip を展開して置くだけでも入ります。</p>
<a class="tako-os-link" href="/getting-started/#macos">macOS の入れ方を見る →</a>
</div>

<div class="tako-os-card is-windows">
<p class="tako-os-name">Windows <span class="tako-os-badge">もう使えます</span></p>

<p class="tako-os-note">GitHub Releases のインストーラー（<code>.exe</code>）を実行するだけ。管理者権限は要りません。</p>
