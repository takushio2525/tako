<section class="tako-section">
<h2 class="tako-section-title"><span class="tako-section-dash">—</span> tako でできること</h2>
<p class="tako-section-lead">ターミナルそのものが AI の作業台になります。人がキーボードでできることは、AI も同じ経路でできます。</p>

<div class="tako-card-grid">

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-pink"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M13 2 3 14h9l-1 8 10-12h-9l1-8Z"/></svg></div>
<h3>内蔵 MCP サーバー</h3>
<p>tako の中で AI エージェントを起動すれば、設定ゼロでペインの分割・コマンド実行・ファイル表示ができます。「隣のペインで dev サーバー起動して」と言うだけ。<strong>128 個</strong>の MCP ツールを内蔵しています。</p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-pink"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="5" r="2.4"/><circle cx="5" cy="19" r="2.4"/><circle cx="19" cy="19" r="2.4"/><path d="M12 7.4v3.6M12 11h-7v5.6M12 11h7v5.6"/></svg></div>
<h3>オーケストレーション</h3>
<p><code>tako master</code> で司令塔の AI を起動すれば、複数の子エージェントが同じタブのペインに並んで働きます。依頼は自然言語で 1 回だけ。監視も検収も片付けも自動。<a href="/features/orchestration/">詳しく →</a></p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-green"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><rect x="3" y="3" width="18" height="18" rx="2.5"/><path d="M3 9h18M11 9v12"/></svg></div>
<h3>タブ＆ペイン管理</h3>
<p>iTerm2 ライクな分割レイアウトにドラッグ＆ドロップ対応。エージェント・dev サーバー・ログを 1 タブにまとめられるので、どのプロジェクトで何が動いているか一目でわかります。複数ウィンドウにも対応。</p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-green"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M21 12a9 9 0 1 1-3-6.7"/><path d="M21 4v5h-5"/></svg></div>
<h3>再起動しても消えない</h3>
<p>tmux バックエンドにより、tako を閉じて再起動しても実行中のプロセスと画面内容がそのまま復元されます。エージェントの長時間タスクも dev サーバーもそのまま。「任せて寝る」が現実的にできます。</p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-pink"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M14.5 2H7a2 2 0 0 0-2 2v16a2 2 0 0 0 2 2h10a2 2 0 0 0 2-2V6.5Z"/><path d="M14 2v5h5"/><path d="M9 13h6M9 17h4"/></svg></div>
<h3>プレビューと git</h3>
<p>コード・Markdown・画像・PDF・動画をペイン内で表示。210 以上の形式にシンタックスハイライトが効きます。git パネルからはステージング・コミット・ブランチ切替・マージまで行えます。</p>
</div>

<div class="tako-card">
<div class="tako-card-icon tako-card-icon-green"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><rect x="6" y="2" width="12" height="20" rx="2.5"/><path d="M11 18.5h2"/></svg></div>
<h3>スマホからリモート監視</h3>
<p><code>tako remote start</code> と Tailscale で、tailnet 内限定の固定 URL からスマホでも様子を見られます。通信は WireGuard で暗号化され、接続には Mac 側での承認が必要。<a href="/features/remote/">詳しく →</a></p>
</div>

</div>
</section>

<section class="tako-section">
<h2 class="tako-section-title"><span class="tako-section-dash">—</span> はじめよう</h2>
<p class="tako-section-lead">インストールしたら、あとは 2 コマンド。設定ファイルを開く必要はありません。</p>

<div class="tako-terminal-block">
<div class="tako-terminal-header">
<span class="tako-dot tako-dot-red"></span>
<span class="tako-dot tako-dot-yellow"></span>
<span class="tako-dot tako-dot-green"></span>
<span class="tako-terminal-title">Terminal</span>
</div>
<div class="tako-terminal-body">
<div class="tako-terminal-line"><span class="tako-terminal-comment"># 1. Homebrew でインストール（推奨）</span></div>
<div class="tako-terminal-line"><span class="tako-terminal-prompt">$</span> <span class="tako-terminal-cmd">brew install --cask takushio2525/tako/tako</span></div>
<div class="tako-terminal-line">&nbsp;</div>
<div class="tako-terminal-line"><span class="tako-terminal-comment"># 2. 質問ゼロの自動セットアップ（初回のみ。MCP 登録も自動）</span></div>
<div class="tako-terminal-line"><span class="tako-terminal-prompt">$</span> <span class="tako-terminal-cmd">tako setup</span></div>
<div class="tako-terminal-line">&nbsp;</div>
<div class="tako-terminal-line"><span class="tako-terminal-comment"># 3. 司令塔の AI を起動して、あとは日本語で頼むだけ</span></div>
<div class="tako-terminal-line"><span class="tako-terminal-prompt">$</span> <span class="tako-terminal-cmd">tako master</span></div>
</div>
</div>
