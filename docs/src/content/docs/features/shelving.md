「処理は動かしたまま、画面からは一時的に消したい」ターミナルのための機能です。

## 使い方

### ペインの退避

ペインのタイトルバーにある「ー」ボタンをクリックすると、そのペインがたまり場に退避します。プロセスは動いたまま、画面からだけ消えます。

- 「ー」= 退避（プロセスは生きている）
- 「×」= 終了（プロセスを kill する）

### タブの一括退避

タブバーの「ー」ボタンを押す（またはタブをたまり場ドロワーへドラッグする）と、**タブが 1 単位のまま**たまり場へ退避します。中のペインがバラバラになることはありません。

- 分割のしかた（縦・横）と比率がそのまま保たれます
- 手動で付けたタブ名・ペイン名もそのまま残ります
- 元のウィンドウと、タブバー上の並び位置も覚えています

たまり場ドロワーとサイドバーには、**タブバーのタブと同じ形をしたカード 1 枚**として出ます。状態ドット（中のペインをまとめた色）・タブ名・ペイン数のバッジが載っていて、中のペインがサムネイルとしてバラバラに並ぶことはありません。カードにマウスを乗せると、中の全ペインの画面をまとめてプレビューできます。

サイドバー側のカードは `▸` を押すと中のペインの行が開き、1 本だけ取り出したり終了したりできます。

### 退避ペインの確認

ステータスバーの「⏏ 退避」ボタン（退避中ペイン数のバッジ付き）をクリックすると、たまり場ドロワーが開きます。

ドロワーには退避中ペインが**横並びのプレビューカード**で表示されます。各カードにはペインの画面**全体**が縮小して映り（端の数行だけが切り取られることはありません）、ライブで内容が更新されます。カードの幅は画面の縦横比に合わせて決まり、プレビューペインは本文の頭・画像・PDF の今のページが映ります。

字が小さくて読めないときは、カードにマウスを乗せてください。画面全体が読める大きさ（窓の 6 割まで）で浮かびます。

退避中のペインは小さく縮めて描くだけで、**ペイン自体の大きさは変えません**。ドロワーを開いても、退避中の claude などの表示が崩れることはありません。

### 復帰

たまり場から戻す方法は 3 つ:

1. カードの「復帰」ボタンをクリック — 元のタブにペインが戻る
2. カードのタイトルバーをドラッグして、ペインエリアにドロップ — ドロップ位置にペインが挿入される
3. 退避タブのカードを**どこでもクリック** — **分割・比率・並び位置ごと**タブが元に戻る

退避タブから 1 ペインだけ取り出すこともできます（サイドバーのカードで `▸` を開き、そのペインの「復帰」を押す）。取り出したぶんは退避タブの分割ツリーから抜け、全部取り出すと退避タブのカードは消えます。

退避タブを戻す先は、退避したときのウィンドウの、退避したときの位置です。そのウィンドウが既に閉じていれば今アクティブなウィンドウへ、位置がタブ数を超えていれば末尾へ戻ります。

### 完全に破棄

カードの「×」ボタンで「完全に破棄?」の確認が出ます。「はい」を選ぶと tmux セッションごと終了します。

退避タブのカードの右端にも「×」があります。こちらはタブバーのタブの「×」と同じ意味で、確認のあと**そのタブの中のペインをまとめて**終了します。カード本体のクリック（復帰）とは分かれているので、「×」を押しても勝手に復帰することはありません。

### 器なし（中身の無いカード）

赤い破線の枠で「器なし（GUI 再起動で失われた）」と出るカードは、中身を抱えていた tmux セッションなどが既に無い、名前だけ残った退避です。「復帰」は出ません。「×」→「はい」で**一覧から外すだけ**で、ほかのペインの tmux セッションには一切触りません。

## タブ別・master 別の分離

退避ペインは元のタブ（由来タブ）を記録しています。たまり場ドロワーやサイドバーの tmux ビューでは、由来タブごとにグループ分けして表示されます。

ドロワーでは由来タブの中をさらに**親の master ごと**の見出しで分けます。見出しには master のプロファイル名とタイトルが出て（master 自身が退避中なら「退避中」と添えます）、master 自身のカードはその見出しの先頭に `master` の印付きで並びます。worker が分割して作った補助のペインも、元の master の見出しに入ります。親の master が既に閉じていれば「親 #番号 は閉じた」、分からなければ「親 master なし」の見出しになります。この関係は tako を再起動しても保たれます。

復帰操作はデフォルトで由来タブにペインを戻します。由来タブが既に閉じている場合は、現在アクティブなタブに復帰します。

## AI からの操作

```bash
# ペインをバックグラウンドへ退避（プロセスは生きたまま）
tako background --pane <pane-id>

# タブをまるごと退避（分割・比率・並び位置を保ったまま）
tako background --tab <tab-id>

# 退避中ペイン / 退避タブの一覧を JSON で表示
tako backgrounded

# 退避ペインを画面に復帰（省略時は由来タブへ戻る）
tako foreground <pane-id>

# 退避タブをまるごと復帰（元のウィンドウの元の位置へ）
tako foreground --tab <tab-id>
```

`tako backgrounded` の出力は 3 段になっています。

- `backgrounded` — バックグラウンドのペインの平坦な一覧。退避タブの中のペインも `shelved_tab` 付きで載るので、1 本だけ取り出したいときはこちらを見ます。各ペインの `vessel` は中身を抱えているもの（`tmux` / `direct` / `preview` / `web`、`none` は器なし）、`parent_master` は親の master です
- `tabs` — 退避タブの一覧（`tab` / `title` / `origin_window` / `panes` / `tree`）
- `groups` — ドロワーと同じ「由来タブ → 親 master」のまとまり（`origin_tab` / `title` / `origin` / `count` / `masters`）

`tako list` の `shelved_tabs` からも同じ情報が読めます。

MCP からは `tako_background_pane` / `tako_foreground_pane` / `tako_background_list` / `tako_background_kill` で同じ操作ができます（タブ単位は `tab` 引数）。AI エージェントが「使い終わったペインを片付ける」「退避していたペインを取り出してユーザーに見せる」といった操作を自律的に行えます。
