## 安全性の作り

公開インターネットには出しません。通り道と、2 つの関門は次のとおりです。

<RemoteSafety />

- **層① Tailscale のノード確認**: tailnet にログインした端末だけが届き、tako 側でも Tailscale が保証する身元を確かめます。tako 自身は `127.0.0.1` だけで待ち受け、LAN や外からは直接つながりません
- **層② 機器ペアリング**: tailnet の中の端末でも、**Mac の画面で承認するまで画面のデータを 1 つも受け取れません**。QR と URL は恒久固定で、合言葉やトークンを含みません
- **記録は中身を持たない**: 接続・ペアリング・入力のバイト数は監査ログに残りますが、画面の中身と入力した文字は残しません

権限（role）は 4 段です。

<table>
<thead><tr><th>role</th><th>できること</th></tr></thead>
<tbody>
<tr><td><strong>Observe</strong>（既定）</td><td>画面を見るだけ</td></tr>
<tr><td><strong>Interact</strong></td><td>+ テキスト入力・承認応答・コマンドの実行・tako のツリーにあるファイル</td></tr>
<tr><td><strong>Manage</strong></td><td>+ ペインを閉じる・リサイズ・新しく立ち上げる・PC 全体のファイル（このマシン）とショートカット</td></tr>
<tr><td><strong>Admin</strong></td><td>+ 端末管理（一覧・失効）</td></tr>
</tbody>
</table>

**権限を上げられるのは Mac の画面だけです。** AI・CLI・スマホからは「お願い」までです。スマホで権限が足りない画面には「権限の更新をリクエスト」が出て、送ると Mac に承認ダイアログが出ます。許可されれば、スマホは読み込み直さずに続きができます。**下げる・消すのは CLI / MCP からもできます**（置き忘れた権限をその場で畳めるほうが安全側なので）。端末ごとの権限は **設定 → リモート** で選び直せ、ステータスバーの「リモート」からは全端末をまとめて切る停止もできます。

<Cmd>tako remote devices list</Cmd>

:::caution[これは正規の遠隔操作ツールです]
Interact 以上を許可した端末は、ブラウザから**あなたのターミナルへ任意のコマンドを送れます**（実質的にシェルへのフルアクセス）。自分の端末を自分で操作する目的でだけ使ってください。

- **知らない端末の承認ダイアログが出たら「拒否」してください**
- 共有の tailnet などで、**その中の全端末を信頼できるとは限らないなら、この機能は使わないでください**
- Tailscale アカウントの 2 要素認証と tailnet lock も有効にしておくと安心です
:::

## 起動していれば、再起動しても戻る

一度 `tako remote start`（またはステータスバーの「リモート」の起動ボタン）で起動すれば、**tako や Mac を再起動しても自動で立ち上がり直します**。止めるのは `tako remote stop` を 1 回。そのときは「起動していた」という記録も消えるので、以後は勝手に戻りません。戻せなかったときは、理由がステータスバーのリモートの表示と `tako remote status` に出ます。

tako を起動した直後など、立ち上げ直している途中に `tako remote start` / `tako remote stop` を打つと、「終わるまで待つ」と断ります（2 本目を起こさないため・止めても立ち上げ直しが戻してしまうため）。数秒〜数十秒で終わるので、`tako remote status` を読み直してから打ち直してください。

<Cmd>tako remote status</Cmd>

## よくある質問

**Q: スマホで開くと 502 になる**

Tailscale の `serve` が tako の待ち受けへつながっていない状態です。`tako remote start` はこれを起動の時点で見つけ、理由と次の一手を出して止まります。アプリ版の Tailscale はサンドボックスの制約で Unix ドメインソケットへつなげないため、tako は既定でループバックの TCP を使います。`TAKO_REMOTE_ENDPOINT=unix` を自分で設定しているなら、それを外して `tako remote stop && tako remote start` をやり直してください。

**Q: Mac に Tailscale が 2 つ入っている（アプリ版と `tailscaled`）**

2 つは別々の端末として tailnet に登録されます（名前の末尾に `-1` が付くのはこのため）。どちらを使うかは `tako remote setup` で選べます。選び直すなら `tako remote setup --tailscale auto`（アプリ版があればそれ）か `--tailscale standalone`（自分で動かしている `tailscaled`）。いまどちらかは `tako remote status` の `tailscale_variant` に出ます。

**Q: 証明書の公開ログにホスト名が載るのが気になる**

Tailscale が HTTPS の証明書を取るとき、`<マシン名>.<tailnet>.ts.net` が公開ログに載ります（Tailscale の仕様）。マシン名に知られたくない情報を入れないでください。

**Q: v0.5 以前の URL（trycloudflare.com / tako-remote.pages.dev）は使える？**

いいえ。v0.6.0 で削除しました。移行手順は [リモート接続の移行ガイド](/guides/remote-migration/) にあります。
