AI に「このコマンドを実行してください」と言われて、画面からコピーして貼ったら動かなかった。tako の**コマンドカード**は、その原因ごと取り除きます。AI はコマンドを会話に書く代わりに**カード**で渡し、あなたは「コピー」か「新規ペインで実行」を押すだけです。

スクロールすると、画面がその手順の状態に変わります。

## AI に出してもらうには

`tako master` / `tako solo` で立てた AI と、その worker は、何も言わなくてもカードで渡します。tako の MCP を繋いだほかの AI でも、「カードで出して」と頼めば出せます。

自分で出すこともできます。打ったペインの下にカードが出ます。

<Cmd>tako show-command "npm install"</Cmd>

## CLI と MCP から同じ操作

カードのボタンは、CLI と MCP（`tako_show_command`）と同じ処理を通ります。人が押しても AI が押しても、結果は同じです。

| やりたいこと | CLI | MCP の `action` |
|---|---|---|
| カードを出す | `tako show-command "npm test"` | `show`（省略時） |
| 出ているカードと実行の記録を見る | `tako show-command --list` | `list` |
| コピーする | `tako show-command --copy` | `copy` |
| 新しいペインで実行する | `tako show-command --run` | `run` |
| 閉じる | `tako show-command --dismiss` | `dismiss` |

対象は省略すると最新のカードの 1 件目で、`--card` と `--index` で選べます。オプションの一覧は [CLI リファレンス](/guides/cli-reference/#tako-show-command) にあります。

## 知っておくこと

- カードが出るのは、AI がツールで渡したときだけです。会話に書かれたコマンドを tako が見つけてカードにすることはしません（画面の文字からは、折り返しと本物の改行を見分けられないため）
- カードはその場かぎりです。tako を終了すると消え、再起動しても戻りません
- 1 枚に 10 件まで、1 つのペインに 3 枚までです。超えると古いカードから消えます
- 改行とタブ以外の制御文字を含むコマンドは受け付けません（クリップボードやシェルに、見えないエスケープシーケンスが紛れ込まないように）。1 コマンドは 4096 バイトまでです
