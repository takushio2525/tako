このページは **tako アプリ**（ターミナル本体）が扱う情報の説明です。このドキュメントサイトの閲覧の計測と Cookie については、takushio2525.com 共通の[プライバシーポリシー](https://takushio2525.com/privacy/)を見てください。

## 要点

- tako にアカウントはありません。アプリの中にアクセス解析や広告の仕組みもありません。
- 運営者が受け取るのは、あなたが**有効にしたときのエラーレポートだけ**です（既定は無効）。
- 何もしなくても動く外向きの通信は 2 つあります。**更新の確認**（GitHub へ）と、**AI 自動リネーム**（claude CLI が入っていれば、あなたの Claude アカウントで Anthropic へ）です。どちらも下で詳しく説明します。
- ターミナルに表示された出力は、既定で**端末の中に**平文のログとして残ります（外へは送りません）。

## 何もしなくても動く通信

| 何を | どこへ | いつ | 止め方 |
|---|---|---|---|
| tako の版（通信の `User-Agent`）。`gh` にログインしていれば、その GitHub のトークンも付けます（API の回数制限をゆるめるため） | GitHub（`api.github.com`） | 起動後、24 時間ごと（失敗したら 1 時間後に再試行） | いまは止める設定がありません |
| **AI 自動リネーム**: タブ内の各ペインの作業ディレクトリ（ユーザー名を含むパス）、ターミナルのタイトル、実行状態、**画面の末尾 6 行**（1 行 120 文字まで） | Anthropic（あなたの PC の `claude` コマンドを、あなたのアカウントで 1 回実行します） | 画面の内容が変わって落ち着いたとき。最初は 30 秒、名前が付いた後は 5 分以上あけます | `tako autorename off`、または設定画面の「一般 → AI 自動リネーム」 |

AI 自動リネームは、画面に表示されているものをそのまま材料にします。**画面にトークンやパスワード、他人の個人情報を表示している間は、それも送られることがあります。** そうした作業をするときは、先に `tako autorename off` で止めてください。送った内容は、あなたの Claude の利用規約とプライバシーポリシーのもとで扱われ、あなたの利用枠を消費します。claude CLI が見つからない環境では送らず、タイトルと作業ディレクトリから名前を付けます。

## 有効にしたときだけ動く通信

| 機能 | 何を | どこへ | 有効にする方法 |
|---|---|---|---|
| [エラーレポート](/features/telemetry/) | クラッシュ時の版・OS・エラーの内容（パスなどはマスク） | 運営者（Cloudflare Workers。90 日で自動削除） | `tako telemetry on` |
| [リモートアクセス](/features/remote/) | ペインの画面・入力・ファイル | **あなた自身の端末**（Tailscale のネットワーク内。Tailscale は接続の仲介をします） | `tako remote start` |
| Claude 公式の Remote Control | claude の会話 | Anthropic（claude.ai） | プロファイルで `--remote-control true` |
| AI 系の設定の共有 | `~/.claude/CLAUDE.md`・tako の設定など（秘密らしい値は送る前に止めます） | **あなたが指定した** git のリポジトリ | `tako config` |
| セットアップの導入 | 公式インストーラーの取得 | Anthropic・OpenAI・Homebrew など各配布元 | `tako setup` で [y/N] に答えたとき |

## エージェント CLI（claude / codex / agy）について

tako は、あなたの PC にある claude・codex・agy のコマンドを起動して画面に並べます。**エージェントとの会話は、tako を経由せず、それぞれの CLI から各社へ直接送られます。** 扱いは各社の規約とプライバシーポリシーに従います。

- Anthropic（Claude Code）: [プライバシーポリシー](https://www.anthropic.com/legal/privacy)
- OpenAI（Codex CLI）: [プライバシーポリシー](https://openai.com/policies/privacy-policy/)
- Google（Antigravity）: [プライバシーポリシー](https://policies.google.com/privacy)

## 端末の中に保存するもの

置き場（以下 `<データディレクトリ>`）は、macOS が `~/Library/Application Support/tako`、Windows が `%APPDATA%\tako` です。

| 何を | 既定 | 保存期間 | 止め方・消し方 |
|---|---|---|---|
| **ペインの平文ログ**（ターミナルに表示された出力。表示されたトークンやパスワードも含みます） | 有効 | 容量の上限（ペインごと・全体）を超えたら古い順に消します。期間の上限はありません | `tako logs set --enabled false`。消すときは `<データディレクトリ>/pane-logs/` を削除 |
| 診断ログ（`persist.log` など。ペインの中身・送った文字・トークンは書きません） | 有効 | 容量の上限でローテーション | `<データディレクトリ>` のファイルを削除 |
| レイアウト・会話の一覧・引き継ぎ・タスク | 有効 | 消すまで | `<データディレクトリ>` のファイルを削除 |
| リモート接続の端末の登録と鍵 | リモートを使ったとき | 消すまで | `tako remote devices revoke <id>` |

tako は、セットアップや診断のときに、claude・codex の認証の状態（ログイン済みか、どのプランか）を**読むだけ**で、保存も送信もしません。

## AI エージェントに任せるときの注意

tako は、エージェントに確認なしで作業を続けさせる設定を用意しています（プロファイルの「許可プロンプトをスキップ」）。この設定のエージェントは、**あなたの確認を待たずに、ファイルの削除や書き換え、コマンドの実行、ネットワークへの送信を行えます。** 読み込んだ Web ページやファイルに紛れ込んだ指示（プロンプトインジェクション）に従ってしまうこともあります。

- **既定の状態**: claude は確認あり、codex は確認あり（確認とサンドボックスの両方を外す設定を別に明示したときだけ外れます）、**agy は確認なし**です。
- claude で確認を外すと、tako は Claude Code 自身が最初に出す警告の画面を出さないように設定します。
- 確認を外すのは、失っても困らない作業用のフォルダ、または仮想マシンやコンテナの中にとどめてください。本番環境の認証情報や、大切なデータがある場所では外さないでください。
