tako

入れ方と、使い方。

1入れるダウンロード
2整えるセットアップと更新
3任せるmaster に頼む

1

入れる

ダウンロードとインストール

ターミナルの出力は再現です（抜粋）

1 入れる

Mac は、Homebrew で 1 行。

Apple Silicon の Mac（macOS 11 以降）

ターミナル

~ % brew install --cask takushio2525/tako/tako

==> Downloading tako-v0.8.40-macos-arm64.zip

==> Moving App 'tako.app' to '/Applications/tako.app'

==> Linking Binary 'tako' to '/opt/homebrew/bin/tako'

tako was successfully installed!

~ % tako --version

tako 0.8.40

アプリは「アプリケーション」に入り、tako コマンドも一緒に使えるようになります

1 入れる

Homebrew を使わないなら、zip で。

  1. 1

    GitHub Releases から tako-vX.X.X-macos-arm64.zip をダウンロード

    github.com/takushio2525/tako/releases
  2. 2

    展開して、tako.app を「アプリケーション」へ

  3. 3

    初回に警告が出たら「このまま開く」

    システム設定 → プライバシーとセキュリティ にあります。署名していない配布物のためで、一度許可すれば次からはそのまま開けます
1 入れる

Windows は、インストーラーを実行。

  1. 1

    GitHub Releases の tako-vX.X.X-windows-x86_64.exe を実行

    Windows 10（1809 以降）/ 11・x64。管理者権限は要りません

Windows 版は、移植の途中です。

使える機能と、まだのものは「Windows 対応状況」にまとめていますtako.takushio2525.com/windows-support

2

整える

起動したあとのセットアップとアップデート

2 整える

Claude Code が、まだ無いときは。

  1. 案内に「Claude Code を入れる」ボタンが出ます

    押すと、表示されたコマンドを新しいタブで実行します（管理者権限は使いません）

  2. ログインがまだなら「ログイン」ボタン

    ブラウザが開きます。済むと、案内は自動で次へ進みます

Codex CLI / Antigravity CLI でも使えます（一部の機能は Claude Code だけ）

2 整える

アップデートは、3 つの方法で。

アプリの中で

新しい版が出ると、画面の上に「アップデートがあります」

「詳細を見る」→「今すぐ更新」。終わると自動で再起動します
コマンドで

tako update check → tako update apply

Homebrew で

brew upgrade --cask takushio2525/tako/tako

更新のあとは tako setup をもう一度。新しい設定項目に追従します

3

任せる

master を起動して、仕事を頼む

3 任せる

覚えておくと、便利なこと。

tako master --tab

専用のタブで、司令塔を起動

tako solo

担当を立てずに、1 対 1 で相談

brew install tmux

tmux があると、tako を閉じても作業が続きます

開き直すと、実行中の画面ごと元に戻ります

プロジェクトの追加や設定の変更も、master に日本語で頼めます

tako

この 3 つで、始められます。

1

$brew install --cask takushio2525/tako/tako

2

起動する（初期設定は自動。あとからは tako setup）

3

$tako master
